# NEXTGEN SPORTS — Cinematic Homepage Starter

## Included
- `index.html`: responsive black-and-gold cinematic homepage.
- Navigation links and mobile menu.
- Indoor, Outdoor and Mind Sports sections.
- Journey, mission, contact and footer sections.

## Run locally
Open `index.html` in a modern browser.

## Publish with GitHub Pages
1. Create or open your GitHub repository.
2. Upload `index.html` to the repository root.
3. Commit the file.
4. In Settings → Pages, select Deploy from a branch and choose `main` / root.
5. Save and open the Pages URL after deployment.

## Before publishing
- Replace `REPLACE-WITH-YOUR-OFFICIAL-EMAIL` with your official contact email.
- Review all wording and images.
- The registration button is currently a placeholder. This starter does not yet save athlete data, authenticate users, or provide an admin dashboard.
- Connect a secure backend (for example, Supabase) before collecting personal information.
- For athletes under 18, implement parent/guardian consent and appropriate child-safety and privacy safeguards.

Images are loaded from Unsplash URLs and therefore require an internet connection.
